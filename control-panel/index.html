Bot 清理 / 卸载

先预检，再清理。默认保护 default 和普通 codex-assistant-1..9；单个 Bot 卸载不会删除共享 Codex Home，也不会删除飞书开发后台 APP。

未创建残留清理

清理没有进入 bridge.instances.json 的半成品 workspace、registration 缓存或 runtime 目录。

正式 Bot 卸载

只开放垂类 Bot。流程会检查 active run，停止 Bridge，删除 watchdog，移出集中实例配置，并按选项清理本机目录。

空间卸载

卸载某个垂类空间下的全部正式 Bot，并可同时清理半成品残留和该空间 Codex Home。飞书开发后台 APP 仍需最后手动删除。

最近问题

从各 Bot 最近日志中提取真正异常，已过滤 lark-cli 正常启动、连接和监听提示。

系统自检

只读检查当前设备的控制面板、加载中 个 Bot、watchdog、Provider 环境变量、本地代理和关键文件路径，不会重启或修改配置。
